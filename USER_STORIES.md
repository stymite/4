# LearnHub – User Stories

1. **Sign up.** As a new learner, I want to create an account with a username, email and password so that my progress and favorites are saved to me.
2. **Sign-up errors.** As a new learner, I want clear error messages when my registration is invalid (empty fields, bad email, short or duplicate account) so that I know how to fix it.
3. **Log in.** As a returning learner, I want to log in with my email and password so that I can get back to my personal library.
4. **Login errors.** As a learner, I want to see an error when my credentials are wrong so that I know my login failed and can retry.
5. **Browse the home screen.** As a learner, I want a home screen with the LearnHub logo and a searchable list of books so that I can discover learning material.
6. **View details.** As a learner, I want to tap an item's arrow icon to open a detail screen with author, year, pages and topics so that I can decide whether it suits me.
7. **Save favorites.** As a learner, I want to mark books as favorites and see them on a favorites/profile screen, stored on my device, so that they are still there after I restart the app.
8. **Settings.** As a learner, I want a settings menu (gear icon) leading to a settings screen where I can see my account, toggle dark mode and manage reminders so that the app fits my preferences.
9. **Notifications.** As a learner, I want to configure study reminders and send a test notification so that I can be sure I will be reminded to study.
